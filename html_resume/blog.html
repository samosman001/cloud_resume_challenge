Friday, September 19th, 2026

Today, I finally figured out how to validate my Amazon Certificate Manager (ACM) certificates. I had to switch the domain's name servers
to match the hosted zone's name servers. It was confusing because both the domain and hosted name are "osmantech.net".

I also realized that although I created IaC templates using AWS CloudFormation in the past, it would be better to use Serverless Application Manager
(SAM) templates. The reason why is because that's what the Cloud Resume Challenge recommends doing (and they are probably better).

This Cloud Resume Challenge website is now live as "resume.osmantech.net" as of right now! After validating the ACM certificates, I was able to
create the resume.osmantech.net subdomain and add an A record that links it to the Amazon CloudFront Distribution that is contained in a sub-account

This was somewhat challenging because I did not think that I could use a sub-domain in a root account to direct traffic to a CloudFront distribution
that is located within a sub-account. I thought there might be some type of "barrier".

I suppose, in the Cloud, the sky is the limit!

Monday, September 7th, 2026

I should have started this blog a long time ago! This resume website is already near completion as of this writing.

I learned how to connect these services:

  • HTML Resume with CSS styling.
  • Uses AWS CloudFront CDN to access this website.
  • Deploys via Git to GitHub and then uses GitHub Actions to automatically deploy to AWS S3 Bucket.
  • Visitor counter uses API Gateway and a lambda function to store and retrieve data from an AWS DynamoDB.
  • Contact form uses API Gateway and a lambda function to store input data to an AWS DynamoDB.
